Instancias de solomon descargadas desde https://www.vrp-rep.org/datasets.html

Para la ejecución usaremos dataset de las instancias de Solomon, estas son instancias ampliamente utilizadas en esta clase de problemas el uso de estas instancias permite que sean facilmente reproducible y también facilita la comparación de resultados con trabajos anteriores que utilizan los mismos benchmarks.

Estas estan divididas en diferentes ‘familias'

# Ramdon 
 Clientes distribuidos de forma completamente aleatoria y uniforme. Refleja escenarios donde las entregas están muy dispersas.

# Clustered
 Los clientes están agrupados en clusters. Simula zonas urbanas densas o centros comerciales concentrados.

 # Tipo 1 o 2
 Tipo 1: Menor cantidad de clientes y ventanas de tiempo más restrictivas.
 Tipo 2: Mayor cantidad de clientes y ventanas de tiempo más amplias 

 # Y estas se combinan ej: C1, R2, RC2
